# 菜票台账与下载中心实施计划

**Goal:** 实施已评审方案中的独立查询、四项台账及下载中心。
**Spec:** `docs/design/2026-10-08-meal-ticket-query-download-proposal.md`
**Architecture:** 复用核算账，新台账按业务月独立保存，年度汇总从实际流水派生。保留旧下载地址，集中展示报表入口。
**Tech Stack:** Flask、SQLAlchemy、React、TypeScript、openpyxl。

## 约束与决策

- 用户授权先实施，后续根据使用反馈调整；不再次请求方案确认。
- 部门金额采用实际发放；纸质单列；消费先月度录入；清零由外部软件执行。
- 使用当前目录的新功能分支，不自动导入用户文件，不修改运行数据库，不提交或发布。
- 金额整数分，历史更正保留记录；清零不能变成核算待补发。
